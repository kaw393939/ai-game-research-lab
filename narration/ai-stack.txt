Choose languages by the job they need to do. Python is our proposed tool for Blender scripts, geometry checks, and model experiments. TypeScript can support browser viewers. The gameplay language should fit the engine we choose. Libraries such as PyTorch, Transformers, and ONNX Runtime serve model experimentation or inference; they are not substitutes for a game engine. To compare AI coding performance, we will ask for the same feature, the same bug fix, and the same change request, then measure correctness, regressions, and human effort.
