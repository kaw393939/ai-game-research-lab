Programming & agents ​

Can an AI agent implement a small gameplay system, find its defects, and maintain it through changing requirements?

Research status

Untested. No tool or model has been selected.

First experiment: EXP-001 — Movement and interaction ​

  1. Define movement, collision, an interactable object, and a restart condition.
  2. Give each candidate the same specification and starting code.
  3. Test edge cases, request one behavior change, and record regressions.

What to measure ​

  • Correctness against acceptance tests
  • Human review and debugging time
  • Code readability and ability to extend it
  • Repeatability across independent attempts

Next step ​

Choose candidates, record dated official sources, and create a test using the experiment template. Publish the evidence in the register.
