## The question driving the lab

Can the most capable AI tools help a small team build a coherent, playable video game—and where do they still need human judgment?

We will answer with small experiments, versioned artifacts, and honest records of failures as well as successes. Tools change quickly; every result will name its model or version and test date.

## Start here

1. Read the [mission and evaluation method](./guide.md).
2. Pick a [research track](./research/index.md).
3. Use the [experiment template](./experiments/template.md) to define a measurable test.
4. Record the outcome and update the [decision log](./decisions.md).
