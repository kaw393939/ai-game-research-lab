There are three different ways to use AI in modeling: write modeling code, generate mesh data, or assist a specific task inside an existing application. We should test them separately. Blender and Python are our proposed starting point for editable game assets. CadQuery is a candidate for precise, parameter-driven geometry. AutoCAD automation depends on the product and platform; an AI help assistant does not by itself demonstrate prompt-to-model capability. We will compare generated and scripted props by dimensions, editability, cleanup effort, and successful engine import.
