# Game integration

Can AI-assisted code, audio, and art form a coherent and maintainable playable experience?

::: info Research status
Untested. No tool or model has been selected.
:::

## First experiment: EXP-004 — One-room vertical slice

1. Choose a target platform and engine after defining the game requirements.
2. Combine one gameplay loop, a generated prop, and the room soundscape.
3. Playtest the packaged build and profile it on the target hardware.

## What to measure

- Playable loop and clear player feedback
- Frame time, load time, and memory
- Cross-system defects and repair time
- Total human effort and cost from brief to build
